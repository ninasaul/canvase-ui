# Shot vocabulary (Chinese)

Use these terms verbatim in prompts — models on this platform respond to them.

## 景别 shot size

| 术语 | 画面范围 |
| --- | --- |
| 大远景 | 环境为主，人极小 |
| 远景 | 全身 + 大量环境 |
| 全景 | 全身，头顶留白 |
| 中景 | 腰部以上 |
| 中近景 | 胸部以上 |
| 近景 | 肩部以上 |
| 特写 | 面部或物件局部 |
| 大特写 | 眼睛 / 手指 / 零件 |

## 机位与运动 camera

固定机位、缓慢推近、快速推近、缓慢拉远、横摇、纵摇、跟随、环绕、
手持轻微抖动、俯拍、仰拍、过肩镜头、主观视角、低角度、地平线倾斜

## 光位与色温 lighting

侧逆光、正面柔光、顶光、底光、窗光、暖黄夜灯、冷蓝月光、
霓虹混合光、硬光高对比、柔光低对比、逆光轮廓、体积光、环境反光

## 风格 style

写实电影感、纪录片、日系清新、赛博朋克、胶片颗粒、黑白、
3D 渲染、水彩、绘本、黏土、像素、商业广告质感

## 一致性短语 consistency

同一角色的外形描述必须逐字复制，例如：

```
林夏，25 岁，短发染薄雾蓝，右眉尾有一道细疤，米色风衣，白色帆布鞋
```

写进每个镜头，只改动作与景别。
